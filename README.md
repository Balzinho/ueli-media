# ueli-media

The films of "Welcome to Switzerland. There are rules." (the Ueli series) for
www.swissexpatguide.com/ueli, served by GitHub Pages, which answers byte-range
requests (iPhone Safari needs them for video).

- `epNN.mp4`: the current English film of episode NN. A new take replaces the
  file in place.
- The site points at https://balzinho.github.io/ueli-media/epNN.mp4
  (`media()` in src/data/ueliEpisodes.ts of the site repo).

Made with AI tools. Human ideas, AI craft.
